# 第二轮复审实施与验证

日期：2026-11-25（UTC+08:00）。先完成确定性修复并测量发布版本，再增加功能。保留本轮之前的管理员 deny-only SID 授权资格修复。原 Antigravity 两轮交流材料位于本地忽略目录 `artifacts/antigravity-rereview-*`，本文件记录已实施内容与验证边界。

## 确定性修复

- 增强授权取消、启动失败、首帧前退出：自动恢复普通采集一次，保留操作提示；普通恢复失败不会循环，不会再次自动弹 UAC。采集器连接及首帧同时观察实际子进程退出，避免盲等 30 秒。当前用户 IPC 限制保持不变。
- 概览与统计共用连接呈现模型，操作通知与快照独立。非管理员拒绝、取消提示不会被下一帧覆盖。断线、页面切换、暂停恢复和托盘还原都保留“最后观测”标记，两页均可明确恢复普通采集。
- 每块物理磁盘独立计算差分。单盘重置、无效状态、异常区间及总和溢出不影响健康盘；整机合计仅在范围和区间完整时有效。新增/移除设备不会使已有健康盘全部重新预热。
- 退出准备只捕获悬浮条位置并停止采集；设置快照在后台写一次，统计排空失败也始终等待设置保存。系统会话结束预算计入同步准备耗时，耗尽预算不再追加一次完整等待。同步 UI 清理无法抢占，不将局部等待上限宣称为整个退出路径的硬上限。
- 悬浮条以 510×58 DIP 换算当前 DPI 的物理尺寸；关闭期位置读取受保护。使用现有窗口事件/防抖处理显示配置变化。

## 新增功能

- 悬浮条鼠标穿透与背景不透明度（20%–100%）保存到偏好。穿透使用独立原生分层窗口，保持文字清晰；恢复交互回到 WinUI Acrylic。托盘提供明确恢复入口。复用原有采样更新，没有新增轮询计时器。
- 开机启动可选 `--minimized`，主窗口保持隐藏，采集继续，悬浮条遵循已有偏好。手动再次启动唤回原实例；托盘不可用时显示主窗口。
- 应用详情按需查询 TCP/UDP、IPv4/IPv6 端点，每 3 秒一次；关闭、暂停、切页、托盘、断线及退出停止查询。TCP 显示本地/远端/状态，UDP 只显示本地绑定，监听端口无伪造远端。查询前验证创建时间，查询后验证同一进程句柄仍存活；迟到结果与队列中的 UI 更新均检查选择代际。显示上限 200 条，超限或权限不足有明确说明，不做 DNS 查询。

## 实机验证与边界

- 静默启动注册命令核对通过，10 秒采样中没有可见主窗口，普通采集器运行；手动启动恢复同一实例并显示实时状态。该会话正常退出约 534 ms。测试后恢复原启动项、主题与功能开关偏好。记录：`artifacts/rereview-startup-verification.json`。
- 最终发布版应用详情实际显示 Firefox 的 13 条端点。通过父进程与可执行文件路径确认归属后，仅终止本应用的普通采集子进程；概览与统计页均显示“采集已断开 / 最后观测”，切页、暂停恢复及托盘还原没有误报实时，随后恢复普通采集成功。记录：`artifacts/rereview-ui-verification.json`；截图：`rereview-connections-light.png`、`rereview-disconnected-statistics.png`、`rereview-settings-final.png`。
- 浅色与深色穿透均由独立 WinForms 测试进程实际收到点击；确认样式与画面可读性，托盘恢复后 Acrylic 状态为 Attached/Active，深浅色一致。深色初次测试被其他窗口遮挡，已改成点击前验证目标进程并复测通过，不把失败样本当成功。记录：`artifacts/overlay-clickthrough-verification.json`、`overlay-dark-valid/overlay-clickthrough-verification.json`。
- 实机曾发现新增 `AccessibilitySettings.HighContrastChanged` 订阅抛 `0x80070490`，已删除该不兼容事件依赖，改走已有 Windows 设置通知及 Win32 `SPI_GETHIGHCONTRAST`。本轮 23:40:13 的错误日志属于修复前失败样本，保留用于追溯。
- 150%/200% 尺寸换算与负坐标屏幕恢复通过纯测试；本机实测为 100%。没有更改用户显示缩放、注销、关机或拔插设备。真实 Windows 10、混合 DPI、多显卡、完整管理员 ETW 压力以及长期稳定性仍需专项环境；既往未定位的原生退出不因此宣称根治。
