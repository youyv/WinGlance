# 审核后修复与验证

日期：2026-11-25（UTC+08:00）。以 Antigravity 交流报告核对的 `202fbf5` 为基础。本轮实现先处理确定性问题，再进行统计后台基准与性能调整，最后增加设备选择和悬浮条位置恢复。下面区分自动回归、真实桌面操作与尚未完成的环境验收。

## 已修复的行为

- 关闭应用不再把悬浮条开关写成关闭；用户单独关闭悬浮条仍会保存关闭状态。
- 采集器持有并校验父进程句柄，用该对象观察退出，避免先检查退出、再读取创建时间之间的竞态和 PID 复用。
- Catalog 签名验证遍历候选，提前成功或异常时释放仍持有的上下文；支持首个候选失败、后续候选成功。
- 重置统计在事务内清理无剩余日期、会话或运行引用的目录；图标删除失败会在保存及重启时重试。细节见 [统计性能报告](audit-statistics-performance.md)。
- 子进程提示仅显示自身 PID 和路径；自身路径不可读时显示不可访问，不借用父分组路径。
- 两页增强采集按钮共用连接状态；连接/授权中及已增强时禁止重复启动。旧连接退出不能覆盖新连接状态。取消 UAC 后显示可重试状态。
- 标准账户跨账户授权明确提示暂不支持，保持普通采集；没有扩大命名管道 ACL。
- 系统询问结束会话时异步预保存，取消时继续采集；确认结束后停止接收并有界等待最终保存（最多 2 秒），失败或超时写入日志。正常主动退出等待最终保存。

## 新功能与性能调整

网络和磁盘卡片的标题菜单提供设备选择。默认仍是自动活动网卡及全部物理磁盘；选中 ID 保存到设置。断开、预热或缺失设备显示不可用并保留选择，恢复后继续使用同一 ID。网卡列表复用现有 `GetIfTable2` 结果，磁盘复用已有 PDH 原始差分，不新增每秒 PDH query。系统过滤接口/端点被剔除，用户可选虚拟接口单独标注。

网卡选择同时作用于悬浮条；托盘保留自动概览提示。**历史统计仍累计整机物理网卡及物理磁盘**，不随实时卡片选择改变。磁盘 ID 是性能计数器实例名，重分区后可能需重选。

悬浮条位置在拖动停止后 600ms 防抖保存，退出前补存。启动、位置/尺寸及显示工作区变化时，用 Win32 工作区查询将窗口恢复到最近的可用屏幕，支持负坐标。初始化阶段的 WinRT 显示器枚举/监听路径在本机触发异常，桌面测试发现后改为 Win32 查询与显示变化消息；未保留该失败路径。

采集线程维护完整 60 秒历史，UI 仅保留一个待处理刷新，避免排队呈现过时快照。采集序号判断陈旧帧；同一采集器的新序号遇到系统校时回拨会接收新值、重建短时历史。统计图复用有界形状和文本元素，保留缺口、有效零值和主题变化。后台使用有界身份/已提交桶缓存、静态指标枚举和 coverage 脏标记。
