# 运行统计

左侧导航的“运行统计”页展示本次运行、今日、近 7 个自然日的整机汇总和应用排行。它与“资源概览”共享系统进程隐藏偏好；筛选只改变显示，不删除底层数据。页面采用现有主题资源、12px 卡片圆角、青绿色强调、等宽数字。隐藏页面停止查询和绘图，前台每 2 秒更新、每 5 秒自动重排；点击表头立即排序。

## 数据与时间

- 主应用持有统计会话；采集器重连更换 CollectorRunId，但保留主应用会话。CollectorRunId + Sequence 去重。
- 本次运行从主应用启动计时；今日按本地午夜，近 7 天包括今天和前 6 个自然日。只累计实际观测，关闭主应用后不继续采集。暂停概览、导航切换、托盘隐藏均不停止统计。
- 每项指标携带自己的时间区间与有效秒数。应用 CPU 耗时来自 `TotalProcessorTime` / `GetProcessTimes` 的原始 ticks；整机 CPU 来自 `GetSystemTimes` 的忙碌/总 ticks。整机网络与磁盘使用累计计数的整数字节差分，应用网络与磁盘使用 ETW 事件整数字节求和；内存与 GPU 使用采样积分。平均值保留加权积分与有效时长。
- 断档、休眠、计数回退重新建立基线，不用上一帧速率填补缺口。跨午夜的区间增量按时间比例拆分，整数余数保守分配，保持总量；这不代表精确知道每个字节发生在区间内的哪一刻。
- 应用运行时长使用子进程生命周期区间并集；CPU/内存先按同时存在的子进程聚合，GPU 按同一物理引擎聚合后取最忙引擎。峰值是采样峰值，不是连续时间的绝对峰值。
- 应用内存是私有工作集合计；整机内存为总物理内存减可用物理内存。专用/共享显存分开。整机显存来自适配器计数，不使用进程显存相加。容量变化的范围不显示可能误导的容量百分比。
- 资源概览继续展示选定活动网卡；运行统计按硬件物理接口集合累计，接口范围见网络卡片提示。ETW 应用流量与网卡统计口径不同，不做差值推算未归属流量。

普通权限下整机网络/磁盘、CPU/内存可统计，GPU 取决于计数器和驱动。单应用网络/磁盘需要增强采集。没有观测时显示 `—`；历史中已有的部分流量保留，并标记覆盖。丢失事件只报告事件数量和数据不完整，不能据此推算丢失字节。未归属下载、上传、读取、写入单独保留。

无法可靠确认创建时间的进程不计入应用历史；完全发生于两次轮询之间的短命进程无法保证 CPU 统计完整。超过 64 个逻辑处理器时，当前历史整机 CPU 标记为不支持，避免将单处理器组的计数误作整机数据。

## 历史存储

`WinGlance.Statistics` 通过单后台工作队列处理不可变快照，使用 SQLite WAL。数据位于 `%LOCALAPPDATA%\WinGlance\statistics.db`，图标独立保存在同目录的 `StatisticsIcons`。

每秒只更新内存；每 30 秒批量提交一次，正常退出排空队列并提交。事务内写入最终桶值与采集水位；查询合并已持久化与尚未提交增量，避免双计。重置也在同一队列中执行，提交后用时间边界排除旧样本。异常结束可能丢失未提交批次；页面底部显示最近成功保存时间，存储错误在覆盖说明中显示。

- 整机分钟桶保留 7 个自然日。
- 应用最近约 24 小时保留 5 分钟桶，更早归并为小时桶，保留 7 个自然日。
- 会话/日汇总独立保留总量、积分、时长和峰值。当前会话超过 7 天时，汇总仍完整，趋势限定最近 7 天。
- 历史身份与实时分组键分开；普通应用以规范化路径识别，包应用用包/应用标识，共享宿主保守拆分。应用退出仍可查历史，图标不受实时缓存清理影响。
- 同一用户只允许一个主应用实例，重复启动唤回已有窗口，避免重复采集和同时写库。

网络/磁盘占比分母是全部可归属应用总量，不受搜索或系统隐藏影响。综合视角默认 CPU 累计耗时，没有人为综合评分。算力视角展示有效观测期间加权平均及采样峰值。

## 重置

“重置当前统计”会明确确认所选范围，并提示与其他范围重叠的数据也会改变。包括隐藏的系统应用，保留主题、开机启动等偏好。本次运行重置仅移除该会话的贡献；今日/近 7 天按日期清理全部会话在相应范围的贡献。之后从新的采样边界继续。

## 手动导出

顶部“导出”提供 CSV 和 JSON。点击时固定本次运行 / 今日 / 近 7 天、系统隐藏、关键词和排序；选择保存位置后，在统计队列中一次捕获数据，后台采样随后产生的变化不会修改这份快照。导出包含整机汇总和筛选后的应用排行，不含趋势明细。

整机汇总不受应用筛选影响；网络 / 磁盘占比分母采用全部可归属应用总量。搜索和隐藏系统进程仅影响应用行。文件记录点击时间、查询截止时间、最后入账 / 保存 / 重置时间、时区、有效秒数、覆盖率、采样峰值时刻、ETW 丢失和未归属量。未观测的数值在 JSON 为 `null`、CSV 为空；测得的零仍为 `0`。默认不导出可执行文件路径、命令行或图标路径。

JSON 带 `schemaVersion`，数值使用 bytes、seconds、percent 等机器单位；CPU ticks 每个为 100 ns。CSV 使用 UTF-8 BOM 和单一表头，首条数据为整机，其后为应用。可能被表格软件解释为公式的外部文本会增加可见的“文本：”前缀，完成提示说明处理数量，数值字段保持数值。

选择位置和写入期间可以取消；提交阶段开始后取消入口关闭。写入先使用目标同目录的独占临时文件，新建不会覆盖期间突然出现的同名文件，覆盖已有文件使用保留恢复副本的替换流程。失败时页面显示原因及必要的恢复路径，请保留提示中的文件。正常完成会清理临时文件及恢复副本；不承诺断电或所有文件系统故障下的绝对持久性。

导出结果提示独立于统计刷新，切换页面后仍保留。关闭应用会取消尚未提交的导出并等待已登记的后台写入结束；保存对话框本身只选择位置，不提前创建输出文件。
