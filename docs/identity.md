# 软件身份、聚合与历史数据

本文件描述当前实现支持的行为和明确保留的限制。身份分类用于列表筛选，不是安全边界。

## 进程实例与软件分组

- 进程实例使用 `PID + StartTimeUtcTicks`。包身份读取会在同一个进程句柄上核对创建时间，避免 PID 重用后继承旧包身份。
- 普通 Win32 应用使用规范化可执行文件路径与 Windows 会话分组。不同目录下的同名 EXE 不合并；同一路径的多个实例会合并。
- 打包应用同时读取 Package Family、完整包名和 AUMID。只有 AUMID 与包家族一致时才采用包应用身份。分组包含会话、包家族与应用 ID，因此同包内的不同应用不合并。
- `svchost`、`rundll32`、`dllhost`、WebView2、常见脚本运行时等共享宿主没有可靠包应用身份时，按进程实例保持独立。不会仅凭父进程或 EXE 文件名猜测所属应用。
- 当前没有按用户 SID 再细分同会话内的 `Run as different user`；没有将不同 EXE 的未打包辅助进程自动并入主应用。路径标准化也不尝试统一硬链接和所有别名路径。

## 名称与图标

名称优先级为 AppsFolder 本地化显示名、EXE `FileDescription`、`ProductName`、进程名。版本信息通过 Windows/.NET 文件版本接口读取；没有中文资源的应用保留原语言，不机器翻译。Windows MUI 卫星资源依赖文件原位置，移动一个 EXE 不保证继续得到原来的中文描述。

图标在独立 STA 线程使用 Shell `IShellItemImageFactory` 的 `ICONONLY` 获取，优先 AppsFolder 包应用图标，再回退 EXE 图标。请求 64 像素资源，转为 PNG；源文件没有高分辨率资源时不能产生原生高清细节。当前图标缓存不按浅色/深色主题分开。

昂贵工作经过容量为 256 的队列串行执行，不在 UI 线程或每秒采样的同步路径中读取版本、校验签名或提取图标。文件元数据缓存最多 1024 项，包进程缓存最多 2048 项，磁盘 PNG 最多 512 个，目录位于 `%LOCALAPPDATA%\WinGlance\Icons`。

每个文件约两分钟重新检查修改时间、创建时间与长度；变化时重新解析名称、签名与图标。提取前后再次比较文件状态，避免发布更新期间混合的文件信息。被删除或淘汰的图标可在下次元数据检查时恢复。图标键包含文件位置、上述文件状态及尺寸。更新检测最多有两分钟延迟；刻意保持全部文件时间与长度的原地修改没有内容哈希保障，此缓存不是防篡改机制。单个异常 Shell 扩展可能拖延后台队列，UI 会继续显示原名称或占位图。

## 系统与服务分类

隐藏为 `WindowsSystem` 必须同时满足：Windows 的 System32/SysWOW64 目录、明确的核心组件名称规则、通过 WinVerifyTrust 验证的 Microsoft 签名。支持嵌入式签名和目录签名；验证使用本地信任数据，不主动下载撤销信息。`CompanyName` 只用于显示，不作为可信签名证据。

路径不可读、签名未完成或证据不足时使用 `Unknown` 并保持可见。Microsoft 签名的普通应用不会仅因发行者而隐藏。已验证包与应用身份的进程保持 `Application`，因此部分 Windows 自带包应用也会显示，这是保守规则的预期结果。

SCM 服务 PID 每 15 秒在后台刷新。服务映射早于进程创建时间时不采用，避免 PID 重用误标。非 Windows 目录的服务标为 `ThirdPartyService` 并保持可见；Windows 目录中不满足核心规则的进程仍为 `Unknown`。不推测共享服务宿主内各项服务的资源分摊。

## 指标汇总

- 同一软件中的相同进程实例重复项只计一次；不同创建时间的相同 PID 是不同实例。
- CPU、网络、磁盘和私有工作集求和时，任何成员缺失即令该项软件总数为未知。不会把无法读取的数据当作零，也不显示看似完整的部分合计。负数、非有限数与溢出结果同样为未知。
- GPU 按物理适配器与引擎键先跨进程相加，再取最忙引擎。`GpuState=Ready` 且没有引擎实例表示已知空闲；其他状态表示未知。超过 100% 的结果只有极小浮点误差可归一，明显异常返回未知。
- 专用和共享显存为进程记账值的合计；任意成员值缺失时合计为未知。共享映射可能在多个进程内重复记账，不等于物理显存实际使用量。
- 未访问 GPU 的进程是否具有显存计数值由采集器决定；聚合层不会根据没有 GPU 引擎活动就擅自把未知显存设为零。

## 最近 60 秒历史

按快照时间保留不超过 60 秒的数据，而不是固定保存 60 次采样。延迟到达的旧时间戳丢弃，相同时间戳替换最后一项。软件从快照消失或有效采样间隔超过 2.5 秒时写入空值断点，防止将断采期间画成连续曲线。图表应使用点的时间戳映射横轴，并将空值画为断线。

历史最多保存 2048 个软件序列、每个序列 600 点，已退出软件在时间窗口到期后移除。历史仍使用系统时间戳；系统时钟回拨期间的快照会被当作较旧数据，直到时间追上为止。

## 回归验证

```powershell
.tools/dotnet/dotnet.exe run --project tests/WinGlance.Tests
.tools/dotnet/dotnet.exe run --project tests/WinGlance.Tests -- --windows-smoke
```

普通回归覆盖路径分组、共享宿主、包内不同应用、PID 重用、保守分类、GPU 空闲/未知/异常、内存缺失及历史断档。Windows 烟测覆盖真实系统文件签名与中文名称、AppsFolder 图标、服务枚举、缓存文件更新，并启动隐藏的临时测试子进程验证结束任务的创建时间检查、系统/自身保护和正确结束。不会结束已有用户进程。
