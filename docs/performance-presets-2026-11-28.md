## 汇总与结论

IQR 按线性插值计算四分位数之差，单位为 CPU 百分点。每组只有 3 个独立样本，不报告 p95 或显著性结论。

| --- | --- | ---: | ---: | ---: | ---: |

| Acrylic | 全部 | 3 | 3.2456% | 0.3414 | 210.86 |
| 穿透 | 标准 | 3 | 3.4734% | 0.2105 | 215.60 |
| 穿透 | 全部 | 3 | 3.3414% | 0.3983 | 213.70 |

这组数据没有显示“全部”预设带来稳定的 CPU 增长，也不能反过来证明增加指标降低了开销。首轮 Acrylic 标准为 5.0970%，原因未得到独立定位，因此保留而不任意排除；用户后台负载没有受控，期间仅进行了小量文档和 Git 操作，没有构建、测试或大型扫描。不同进程的短时 Private 差异不作为内存优化收益。

保留四种功能预设，不因这组波动做渲染删减。正式 CPU 基线、采集器 / Flush 测量和窗口资源生命周期验证分别见 `performance-ui-2026-11-28.md`、`performance-collection-2026-11-28.md`、`implementation-validation-2026-11-28.md`；它们对应不同冻结版本和实验，不能混为最终包的单一性能保证。长期资源稳定性、高对比度、辅助功能文字缩放与混合 DPI 仍需独立验收。
